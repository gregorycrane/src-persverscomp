# Perseus Version Comparison Reader

Large Language Models have transformed digital philology in a variety of ways. First, we can generate not only servicable translations (a crucial advance since much surviving Greek and most surviving Latin is either not readily available or not available in translation.) Second -- and in my view more important, we can produce word-by-word grammatical analyses and glosses for sources in historical languages such as Greek and Latin. This lower level linguistic support allows readers to probe the source text directly. Third, we can compile these translations and annotations into searchable bilingual databases at scale. Such bilingual resources have long been possible -- we developed such tools for the Homeric Epics by manually producing treebanks and then manually breaking down a literal prose translation into chunks that corresponded  

The main thrust of development at Perseus has been to develop a replacement for Perseus 4 -- for now, the Minium Viable Perseus (Perseus MVP). The goal is to support the core functionality of the now venerable Perseus Digital Library, using not only a new code base but also a new strategy. Perseus MVP uses a minimal computing infrastructure. When readers go from text chunk to text chunk, computation takes place in the browser. The server does not have to maintain a database tht interacts with users. The server only provide data that the user's browser then processes. This drastically reduces the demands on the server -- all the hosting institution has to do is to serve data and that data can, in fact, be downloaded and served by third parties. The serverless architecture also makes the system much less susceptible to hacking.
